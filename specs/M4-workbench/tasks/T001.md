## Ask
Build the Node server and the cascade pipeline per docs/architecture/lld.md §1–§4, §6 and hld.md §3.
1. `src/server/pipeline.ts` exporting `createPipeline({ stt, translator, tts, pair, limits: {translateMs, ttsMs}, events: { turn(u: TurnUpdate), audio(seq: number, chunk: Uint8Array), timing(turnId, point: TimingPoint, serverT: number, vendor?: string) }, context?: TurnText[] })` returning `{ pushAudio(pcm: Int16Array), setContext(ctx: TurnText[]), stop() }`. Each STT final starts an independent turn (seq increments). Empty/whitespace final → state `empty`, no translate. Translate direction: final.lang → the other language of `pair`. Stream translator deltas; cut into settled segments at clause/sentence ends (`, . ? ! ; :` followed by whitespace or end of stream) and send each segment to TTS in order as soon as it settles (overlap). Per-stage timeouts with AbortController; on timeout/failure the turn becomes `failed` with reason like `translate timeout`, keeps srcText, and any later result for it is dropped; later turns never wait. RateLimited → retry once after retryAfterMs. Emit timing points (stt_final, first_translation, first_tts_byte). Translator gets the last 5 TurnTexts as context.
2. Providers in `src/server/providers/`: `stt/deepgram.ts` (live streaming, linear16 16 kHz, multi-language or detect en/es, endpointing; endMs from word end), `stt/openai.ts` (OpenAI realtime transcription session over WebSocket with server VAD, model from OPENAI_STT_MODEL), `translate/openai.ts` (streaming chat completions, model OPENAI_TRANSLATE_MODEL, interpreter instructions from lld §6, never answer), `tts/elevenlabs.ts` (fetch streaming, output pcm_24000, ELEVENLABS_VOICE_ID), `tts/openai.ts` (gpt-4o-mini-tts, response_format pcm 24 kHz), `registry.ts` choosing by STT_PROVIDER / TRANSLATE_PROVIDER / TTS_PROVIDER (fallback to openai when a key is blank), `fake.ts` scripted fakes. Map vendor 429/timeouts/empty to ProviderError kinds.
3. `src/server/index.ts`: http server on PORT (8787) with `POST /api/realtime-session` (mint client secret via OpenAI `POST /v1/realtime/client_secrets` with model OPENAI_REALTIME_MODEL, interpreter instructions for the pair from the JSON body `{pair, context}`, server VAD, input transcription enabled; return only `{value, expiresAt}`), `GET /api/config` (vendor names per stage, no keys), `GET /api/eval-clips` (returns eval/clips.json, [] if absent), static `GET /eval/clips/<id>.wav` from eval/clips/, `POST /api/eval-results` (EvalRun JSON → eval/results/<runId>.json), and WS `/cascade` speaking ClientMsg/ServerMsg from src/shared/contracts.ts (binary up = PCM16 16 kHz; binary down = 4-byte big-endian seq + PCM16 24 kHz). Reply to ping with pong. Never log keys or transcripts at info level.
